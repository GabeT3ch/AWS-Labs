# AWS Labs

Hands-on AWS labs to sharpen skills for DevSecOps and cloud engineering roles.

## What's here

Labs built while studying for the AWS Certified Solutions Architect – Associate (SAA-C03), focused on secure, real-world architecture: IAM, networking, compute, storage, and monitoring.

## How it works

- All labs run from a RHEL 10 workstation using the AWS CLI v2.
- Each lab is built on its own branch and merged into `main` through a pull request.
- Every lab includes its goal, steps, verification, and a teardown to avoid surprise charges.
- No credentials, keys, or account IDs are ever committed.
